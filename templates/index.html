UNDERSTANDING THE PREDICTION

How Grad-CAM Explains the Result

Grad-CAM (Gradient-weighted Class Activation Mapping) is a visualization technique that helps explain which regions of an image influenced the deep learning model's prediction.

01

Identifies Important Regions

Grad-CAM highlights image regions that contribute strongly to the model's classification.

02

Generates a Heatmap

The heatmap uses colors to represent the relative importance of different image regions for the selected prediction.

03

Improves Interpretability

The visualization provides insight into where the model is focusing, making its prediction easier to examine.

Note: Grad-CAM highlights influential regions. It does not independently prove that an image is real or AI-generated.

OUR PROCESS

How It Works

The system follows four steps to analyze an image.

01

Upload Image

Select an image from your device or drag it into the upload area.

02

Preprocessing

The image is converted to RGB and resized to 224 × 224 pixels.

03

Deep Learning Analysis

EfficientNetB0 analyzes the image and calculates its prediction probability.

04

View Results

View the prediction, probabilities, Grad-CAM visualization and PDF report.

ABOUT THE PROJECT

AI-Generated Image Detection

This project uses a trained EfficientNetB0 deep learning model to classify uploaded images as REAL or FAKE. Grad-CAM is used to visualize image regions that contribute to the model's prediction.
